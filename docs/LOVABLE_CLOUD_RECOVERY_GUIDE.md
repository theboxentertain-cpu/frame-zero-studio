# MIZENZA / ميزنزا — Lovable Cloud recovery guide

Use this guide if the MIZENZA preview shows a blank page or reports that `SUPABASE_URL` or `SUPABASE_PUBLISHABLE_KEY` is missing.

## English

### If you are using the studio

1. Reload the MIZENZA preview once. If the message remains, close that preview and reopen it from the existing MIZENZA project in Lovable.
2. Do not create a replacement project or backend, and do not enter environment values into the app, a chat message, or a screenshot.
3. Ask the MIZENZA project owner to check the existing project's Lovable Cloud connection and refresh its environment binding using the available project controls. Do not disconnect or recreate the Cloud project.
4. After the owner confirms the refresh, reopen the preview. Sign in normally and check that a project you already own and its saved work still appear. Do not create or edit a project just to test the connection.

### If the error remains

Send the project owner the approximate time, page you opened, and the exact *setting names* shown in the error. Before sharing a screenshot, hide personal film material, email addresses, session details, and any setting values. Never share passwords, access tokens, or service-role keys.

The names in the error identify missing configuration; filmmakers should not try to supply or guess those values themselves. This guide does not authorize database changes, migrations, or production writes.

## العربية

### إذا كنت تستخدم الاستوديو

1. أعد تحميل معاينة ميزنزا مرة واحدة. إذا استمرت الرسالة، أغلق المعاينة وافتحها من مشروع ميزنزا الحالي في Lovable.
2. لا تنشئ مشروعًا أو قاعدة بيانات بديلة، ولا تكتب قيم الإعدادات داخل التطبيق أو في المحادثات أو لقطات الشاشة.
3. اطلب من مالك مشروع ميزنزا مراجعة اتصال Lovable Cloud بالمشروع الحالي وتحديث ربط الإعدادات من عناصر التحكم المتاحة للمشروع. لا تفصل خدمة Cloud ولا تنشئها من جديد.
4. بعد تأكيد التحديث، افتح المعاينة مجددًا. سجّل الدخول بالطريقة المعتادة وتحقق من ظهور مشروع تملكه مسبقًا وأعماله المحفوظة. لا تنشئ مشروعًا أو تعدّله لمجرد اختبار الاتصال.

### إذا استمر الخطأ

أرسل إلى مالك المشروع الوقت التقريبي، والصفحة التي فتحتها، وأسماء الإعدادات الظاهرة في رسالة الخطأ فقط. قبل مشاركة لقطة شاشة، أخفِ مواد الأفلام الخاصة وعناوين البريد الإلكتروني وتفاصيل الجلسة وأي قيم للإعدادات. لا تشارك كلمات المرور أو رموز الوصول أو مفاتيح الخدمة السرية.

أسماء الإعدادات في رسالة الخطأ تدل على إعداد ناقص؛ لا يحتاج صانع الفيلم إلى إدخال القيم أو تخمينها بنفسه. هذا الدليل لا يجيز إجراء تغييرات على قاعدة البيانات أو تشغيل ترحيلات أو كتابة بيانات إلى بيئة الإنتاج.
